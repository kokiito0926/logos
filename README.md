## λόγος（ロゴス）

論理記号を用いることができる、プログラミング言語である。  
コードの大部分をAIに書いてもらったが、それなりに機能しているとは思う。

***

## 暗黙的引数

定義の右辺で使われるギリシャ文字（`α`〜`ω`）は、関数の引数として自動的に扱われます。  
引数を明示して宣言する必要はありません。

```logos
square ≔ α²
add ≔ α + β
distance ≔ √((α.x - β.x)² + (α.y - β.y)²)
```

上のコードは、次の JavaScript にコンパイルされます。

```js
const square = α => (α ** 2);
const add = (α, β) => (α + β);
const distance = (α, β) => Math.sqrt((((α.x - β.x) ** 2) + ((α.y - β.y) ** 2)));
```

通常の識別子は暗黙的引数にはなりません。  
たとえば `π` は `Math.PI` として扱われ、ギリシャ文字を使わない定義は定数になります。

```logos
pi_value ≔ π
answer ≔ 42
```

```js
const pi_value = Math.PI;
const answer = 42;
```

## 暗黙的戻り値

ギリシャ文字を含む定義は JavaScript のアロー関数に変換されます。  
関数本体は式だけで構成されるため、`return` を書かなくても式の値がそのまま戻り値になります。

```logos
hypotenuse ≔ √(α² + β²)
```

```js
const hypotenuse = (α, β) => Math.sqrt(((α ** 2) + (β ** 2)));
```

このように、Logos では数式をそのまま定義として書くことで、引数と戻り値を簡潔に表現できます。

## 設計思想

Logos は、`function`、引数リスト、`return`、セミコロンのような定型的な記述を減らし、数式をそのまま定義として書けるようにすることを目指しています。

Unicode の論理・数学記号は入力しやすいとは限りませんが、意味を圧縮して読みやすくできる可能性があります。  
また、AI がコードを生成する場面では、記述量の削減にも役立つことを期待しています。  

## 現在使える構文

### 定義

定義には `≔`（または ASCII の `:=`）を使います。  
定義名には英字、数字、アンダースコアを使えます。

```logos
answer ≔ 42
answer_copy := 42
square ≔ α²
cube ≔ α³
```

### 数学定数とリテラル

`π` と `∞` は組み込みの数学定数です。  
また、`⊤` と `⊥` は真偽値リテラル、`∅` は空集合リテラルです。  
JavaScript では以下のように変換されます。

- `π` → `Math.PI`
- `∞` → `Infinity`
- `⊤` → `true`
- `⊥` → `false`
- `∅` → `new Set()`

```logos
circle_ratio ≔ π
unbounded ≔ ∞
flag ≔ ⊤
empty ≔ ∅
```

```js
const circle_ratio = Math.PI;
const unbounded = Infinity;
const flag = true;
const empty = new Set();
```

### 式

現在は次の式を使えます。

| Logos | 用途 | 変換例 |
| --- | --- | --- |
| `+` `-` `*` `/` | 四則演算 | |
| `=` `≠` `<` `>` `≤` `≥` `≡` `≈` | 比較（`=` `≡` は厳密等価、`≈` は `almostEqual`） | `α ≈ β` → `almostEqual(α, β)` |
| `←` | 代入・再代入 | `α ← β` → `(α = β)` |
| `¬` | 否定 | `¬α` → `(!α)` |
| `∧` `∨` `⇒` `⇔` `⊕` | 論理（積・和・含意・同値・排他的論理和） | `α ⇒ β` → `(!α \|\| β)`, `α ⊕ β` → `(α !== β)` |
| `↦` `→` | 明示的アロー関数 (マッピング) | `x ↦ x²` → `x => (x ** 2)` |
| `∘` | 関数合成 | `f ∘ g` → `((...args) => f(g(...args)))` |
| `|>` | パイプライン | `x |> f(a)` → `f(x, a)`, `x |> f |> g` → `g(f(x))` |
| `^` `²` `³` `⁴` `⁻¹` `¹⁰` | べき乗 (任意のUnicode上付き指数) | `α²` → `(α ** 2)`, `α⁻¹` → `(α ** -1)` |
| `x₀` `x₁` `α₁` | 下付き添字 (添字アクセス・暗黙引数) | `x₀ + x₁` → `(x[0] + x[1])`, `α₁ + β₂` → `(α, β) => (α[1] + β[2])` |
| `√` | 平方根 | `√(α)` → `Math.sqrt(α)` |
| `∈` `∉` | 集合の帰属・非帰属 | `α ∈ set` → `set.has(α)`, `α ∉ set` → `(!set.has(α))` |
| `∩` `∪` | 共通部分・和集合 | `A ∩ B` → `new Set([...A].filter(x => B.has(x)))`, `A ∪ B` → `new Set([...A, ...B])` |
| `∖` `×` | 差集合・直積 | `A ∖ B` → `new Set([...A].filter(x => !B.has(x)))`, `A × B` → 直積 `new Set(...)` |
| `⊆` `⊂` | 部分集合・真部分集合 | `A ⊆ B` → `[...A].every(x => B.has(x))`, `A ⊂ B` → 部分集合かつ `A.size < B.size` |
| `‥` | 範囲 | `1‥10` → `range(1, 10)`, `0‥<n` → `range(0, n, true)` |
| `∀` `∃` `∄` | 量化 (全称・存在・非存在) | `∀ α ∈ users : α.age ≥ 18` → `[...users].every(α => α.age >= 18)`, `∃ α ∈ users : ...` → `[...users].some(...)`, `∄ α ∈ users : ...` → `![...users].some(...)` |
| `∑` `∏` | 総和・総積 | `∑ α ∈ numbers : α` → `[...numbers].reduce((acc, α) => acc + α, 0)`, `∏ α ∈ numbers : α` → `[...numbers].reduce((acc, α) => acc * α, 1)` |
| 比較の連結 | チェーン比較 | `0 ≤ α ≤ 10` → `(0 <= α) && (α <= 10)` |
| `⊤` `⊥` | 真偽値リテラル | `true`, `false` |
| `∅` | 空集合リテラル | `new Set()` |
| `()` | 優先順位の指定 | |
| `α.x` | プロパティ参照 | |
| `α[0]` | 添字アクセス | |

### 下付き添字

Unicode の下付き添字は、添字アクセスとして扱われます。  
数学では下付き添字は配列やベクトル、行列などの要素を表すことが多いため、この変換のほうがより自然です。

```logos
x₀ + x₁
```

```js
x[0] + x[1]
```

ギリシャ文字の暗黙引数に対しても同様に動作します。

```logos
dist_sub ≔ α₁ + β₂
```

```js
const dist_sub = (α, β) => (α[1] + β[2]);
```

### チェーン比較

比較演算子を連続して書くと、各比較を `&&` で結合したチェーンになります。  
このとき、中間のオペランドは前の比較の右辺と次の比較の左辺を兼ねます。

```logos
in_range ≔ 0 ≤ α ≤ 10
```

```js
const in_range = α => (0 <= α) && (α <= 10);
```

異なる比較演算子を自由に混在させることもできます。

```logos
between ≔ 0 ≤ α < 10
chain3 ≔ a = b ≠ c ≤ d
```

```js
const between = α => (0 <= α) && (α < 10);
const chain3 = (a === b) && (b !== c) && (c <= d);
```

### 集合演算

`∅` で作った空集合や `Set` を対象に、以下の集合演算が使えます。

| Logos | 用途 | 変換例 |
| --- | --- | --- |
| `A ∩ B` | 共通部分 | `new Set([...A].filter(x => B.has(x)))` |
| `A ∪ B` | 和集合 | `new Set([...A, ...B])` |
| `A ∖ B` | 差集合 | `new Set([...A].filter(x => !B.has(x)))` |
| `A × B` | 直積 | `new Set([...A].flatMap(a => [...B].map(b => [a, b])))` |
| `A ⊆ B` | 部分集合 | `([...A].every(x => B.has(x)))` |
| `A ⊂ B` | 真部分集合 | `([...A].every(x => B.has(x)) && A.size < B.size)` |

```logos
in_both ≔ α ∈ A ∩ B
is_sub  ≔ A ⊆ B
```

```js
const in_both = α => (new Set([...A].filter(x => B.has(x))).has(α));
const is_sub = ([...A].every(x => B.has(x)));
```

集合演算子の優先順位は算術演算子より低く、比較演算子より高いため、`α ∈ A ∩ B` は `α ∈ (A ∩ B)` として解釈されます。  
また `∩` より `∪` が低い優先順位なので、`A ∪ B ∩ C` は `A ∪ (B ∩ C)` になります。

### 量化

集合（または配列）に対する全称・存在・非存在の量化を `∀`, `∃`, `∄` で書けます。  
構文は `∀/∃/∄ 変数 ∈ 集合 : 本体` です。束縛変数は暗黙引数には含まれません。

| Logos | 用途 | 変換例 |
| --- | --- | --- |
| `∀ α ∈ A : P(α)` | 全称量化 (すべての要素が条件を満たす) | `[...A].every(α => P(α))` |
| `∃ α ∈ A : P(α)` | 存在量化 (条件を満たす要素が存在する) | `[...A].some(α => P(α))` |
| `∄ α ∈ A : P(α)` | 非存在量化 (条件を満たす要素が存在しない) | `![...A].some(α => P(α))` |

```logos
all_adult  ≔ ∀ α ∈ users : α.age ≥ 18
has_adult  ≔ ∃ α ∈ users : α.age ≥ 18
no_minor   ≔ ∄ α ∈ users : α.age < 18
```

```js
const all_adult = [...users].every(α => (α.age >= 18));
const has_adult = [...users].some(α => (α.age >= 18));
const no_minor = ![...users].some(α => (α.age < 18));
```

本体はコロンの後の改行に続けて書くこともでき、その場合も最後の式が本体になります。  
また、集合部分には `A ∩ B` などの集合演算をそのまま書けます（`∀ α ∈ A ∩ B : ...` は `(A ∩ B)` 全体に対して量化します）。  
量化の対象は配列と `Set` のどちらでも使えます（スプレッドしてから `every` などで処理します）。

```logos
all_in_both ≔ ∀ α ∈ A ∩ B : α > 0
```

```js
const all_in_both = [...new Set([...A].filter(x => B.has(x)))].every(α => (α > 0));
```

### 総和・総積

集合（または配列）に対する総和・総積を `∑`, `∏` で書けます。  
構文は `∑/∏ 変数 ∈ 集合 : 本体` です。束縛変数は暗黙引数には含まれません。  
生成コードは `reduce` を用います（総和は初期値 `0`、総積は初期値 `1`）。

| Logos | 用途 | 変換例 |
| --- | --- | --- |
| `∑ α ∈ A : f(α)` | 総和 | `[...A].reduce((acc, α) => acc + f(α), 0)` |
| `∏ α ∈ A : f(α)` | 総積 | `[...A].reduce((acc, α) => acc * f(α), 1)` |

```logos
total    ≔ ∑ α ∈ numbers : α
sum_sq   ≔ ∑ α ∈ numbers : α²
product  ≔ ∏ α ∈ numbers : α
weighted ≔ ∑ α ∈ items : α.price * α.qty
```

```js
const total = [...numbers].reduce((acc, α) => acc + α, 0);
const sum_sq = [...numbers].reduce((acc, α) => acc + (α ** 2), 0);
const product = [...numbers].reduce((acc, α) => acc * α, 1);
const weighted = [...items].reduce((acc, α) => acc + (α.price * α.qty), 0);
```

量化と同様に、本体はコロンの後の改行に続けて書くこともできます。  
また、対象は配列と `Set` のどちらでも使えます（`Set` には `reduce` がないため、スプレッドしてから処理します）。

```logos
sum_plus_one ≔ ∑ α ∈ xs :
    α + 1
```

```js
const sum_plus_one = [...xs].reduce((acc, α) => acc + (α + 1), 0);
```

### パイプライン演算子

左辺の式を、右辺の関数の**第一引数**として渡します。データ変換の連鎖を読みやすくできます。

```logos
result ≔ numbers |> filter(isPrime) |> map(square) |> sum
```

```js
const result = sum(map(filter(numbers, isPrime), square));
```

- 右辺が関数参照 `f` のとき: `x |> f` → `f(x)`
- 右辺が関数呼び出し `f(a, b)` のとき: `x |> f(a, b)` → `f(x, a, b)`
- 右辺がメソッド `obj.f(a)` のとき: `x |> obj.f(a)` → `obj.f(x, a)`
- 右辺がアロー関数 `(y ↦ y * 2)` のとき: `x |> (y ↦ y * 2)` → `((y => (y * 2)))(x)`
- 右辺が合成 `f ∘ g` のとき: `x |> f ∘ g` → `(((...args) => f(g(...args))))(x)`

パイプライン演算子の優先順位は最も低いため、`x + 1 |> f` は `f(x + 1)` と解釈されます。

> **注**: `filter`, `map`, `sum` などの関数は JavaScript 側で定義してください。また、関数呼び出し構文 `f(x)` 自体もサポートされました（`√` は従来どおり `Math.sqrt` に変換されます）。

### インデントブロック

`≔` の後に改行とインデントを続けることで、**複数行ブロック**を定義できます。  
ブロック内でローカル変数を定義し、**最後の式を暗黙的に戻り値**とします。  
生成コードはローカル変数を `const` で宣言した**関数スコープ**になります。

```logos
distance ≔
    γ ≔ α.x - β.x
    δ ≔ α.y - β.y
    √(γ² + δ²)
```

```js
const distance = (α, β) => {
    const γ = (α.x - β.x);
    const δ = (α.y - β.y);
    return Math.sqrt(((γ ** 2) + (δ ** 2)));
};
```

- 暗黙引数はブロック全体の自由変数（ギリシャ文字）から自動収集され、ブロック内の定義名は除外されます。
- ブロック内の定義は依存順に並べ替えられるため、**前方参照**（後で定義した名前を先に使う）も可能です。循環参照はエラーになります。
- ブロック内には定義のほか、**式文**（関数呼び出しや再代入 `←` など）も書けます。最後の式文が戻り値になります。
- 本体が式 1 つだけの場合は従来どおりインラインのアロー関数に短縮されます。
- インデントは一貫している必要があります（タブは 4 スペース換算）。インデントを伴わないブロックはエラーになります。
- 量化（`∑`, `∀` など）の本体もコロンの後の改行とインデントで書けます。

### コマンドライン

`.logos` ファイルは CLI で JavaScript にコンパイルできます。  
出力先を指定しない場合は、生成結果を標準出力に表示します。

```sh
zx src/cli.js example/index.logos
zx src/cli.js example/index.logos --output example/index.js
```

利用できるオプションは次のとおりです。

| オプション | 内容 |
| --- | --- |
| `--output`, `-o` | 生成した JavaScript の保存先 |
| `--verbose`, `-v` | トークン、AST、生成 JavaScript を表示 |
| `--help`, `-h` | ヘルプを表示 |

## 今後の構想

以下はメモに記載されている機能拡張・仕様案であり、現在のコンパイラではまだ利用できません。

### 1. 制御フロー

インデントブロックと暗黙戻り値は **実装済み** です（「インデントブロック」の節を参照）。  
今後は条件分岐（`if` / `else`）とループ（`while`）を、英語キーワードではなく**論理記号**で表現する構想です。  
**現在はまだ実装されていません**（以下は構想です）。

| 記号 | 名称 | 意味 |
| --- | --- | --- |
| `⇒` | 含意（if） | `P ⇒ A`：条件 `P` が真のとき `A`。実装済みの論理演算をそのまま分岐に拡張 |
| `⊤` | 恒真（else） | `⊤ ⇒ A`：それ以外の場合。実装済みの真値リテラルで else を表現 |
| `μ` | 最小化演算子（while） | `μ α (P(α))`：`α` を `0,1,2,…` と増やし、初めて `P(α)` が成り立つ最小の `α` を返す |
| `⟦ ⟧` | アイバーソンの括弧 | `⟦P⟧`：`P` が真なら `1`、偽なら `0`。条件を値に変換 |

**構文案**

```logos
# if / else: 含意（⇒）による場合分け
abs ≔
    α ≥ 0 ⇒ α
    ⊤     ⇒ −α

# if を値として扱う（アイバーソンの括弧）
adult ≔ ⟦age ≥ 18⟧

# while: μ 演算子による最小値探索
n ≔ μ α (α² ≥ 100)     # α = 0,1,2,… と増やし α² ≥ 100 になる最小値 (= 10)
```

**変換案（JavaScript相当）**

| 構想 | 変換例 |
| --- | --- |
| 場合分け `P₁ ⇒ A₁, ⊤ ⇒ A₂` | 三項演算子 `P1 ? A1 : A2` |
| アイバーソンの括弧 `⟦P⟧` | `P ? 1 : 0` |
| `μ α (P(α))` | `let α = 0; while (!P(α)) α++; return α;` |

- `⇒` と `⊤` は既に実装済みのため、分岐を追加する実装コストは比較的低い（難易度: **Medium**）です。
- 変数の更新を伴うループは、`←`（代入）と `μ` を組み合わせる案を検討しています。
- `[ ]` は配列リテラルに使うため、アイバーソン括弧は二重ブラケット `⟦ ⟧` としています。

### 2. 表記法・Unicode識別子・型システム構想

- **Unicode数学スタイルの識別子**: 太字 (`𝐀`, `𝐱`)、イタリック (`𝑓`, `𝑥`)、筆記体 (`𝒜`, `𝒳`)、フラクトゥール (`𝔄`, `𝔅`) 等をそのまま識別子としてサポート
- **型注釈構想 (TypeScript等へのコンパイル)**: 黒板太字 (`ℕ`, `ℤ`, `ℝ`, `ℂ`) を型注釈として利用 (例: `age : ℕ`)

### 3. 微積分記号の活用

`∫`（積分）・`∂`（偏微分）・`∇`（ナブラ）・`∮`（周回積分）などの微積分記号を、数式のまま書く構想です。  
**現在はまだ実装されていません**（以下は構想です）。

| 記号 | 名称 | 意味 |
| --- | --- | --- |
| `∫` | 積分 | `∫ f(α) dα`：不定積分（原始関数）。`∫₀¹ f(α) dα`：定積分（面積） |
| `∂` | 偏微分 | `∂f/∂α`：他の変数を固定した `f` の `α` による微分 |
| `∇` | ナブラ | `∇f`：全変数による偏微分のベクトル（勾配） |
| `∮` | 周回積分 | 閉曲線に沿った複素積分 |

**構文案**

```logos
area      ≔ ∫₀¹ α² dα        # 定積分（面積）
antideriv ≔ ∫ f(α) dα        # 不定積分（関数を返す）
deriv     ≔ ∂(α² + β²)/∂α    # 偏微分
grad      ≔ ∇f               # 勾配ベクトル
```

定積分の範囲には、既存の下付き・上付き文字（`₀`, `¹`）を利用します。

**変換案（2系統）**

| 方式 | 仕組み | 特徴 |
| --- | --- | --- |
| **数値計算** | `∫₀¹ f dα` → シンプソン則などの数値積分。微分は有限差分 `(f(α+h) − f(α−h)) / 2h` で近似 | 汎用・実装が容易。近似値のみ |
| **記号微分** | AST を連鎖律・積の法則で変形し、`∂(α² + β²)/∂α` → `2α` のような**厳密な式**を出力 | 正確。Logos の「数式をそのまま書く」思想に合致 |

- `∮`（周回積分）は複素数ランタイムが必要なため、実装コストが高い（難易度: **Hard**）です。
- 微分の別表記として、`f′`（プライム）による導関数の表現も検討しています。
