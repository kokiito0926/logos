## λόγος（ロゴス）

論理記号を用いることができる、プログラミング言語である。  
コードの大部分をAIに書いてもらったが、それなりに機能しているとは思う。

***

## 暗黙的引数

定義の右辺で使われるギリシャ文字（`α`〜`ω`）は、関数の引数として自動的に扱われます。  
引数を明示して宣言する必要はありません。

```logos
square ≔ α²
add ≔ α + β
distance ≔ √((α.x - β.x)² + (α.y - β.y)²)
```

上のコードは、次の JavaScript にコンパイルされます。

```js
const square = α => (α ** 2);
const add = (α, β) => (α + β);
const distance = (α, β) => Math.sqrt((((α.x - β.x) ** 2) + ((α.y - β.y) ** 2)));
```

通常の識別子は暗黙的引数にはなりません。  
たとえば `π` は `Math.PI` として扱われ、ギリシャ文字を使わない定義は定数になります。

```logos
pi_value ≔ π
answer ≔ 42
```

```js
const pi_value = Math.PI;
const answer = 42;
```

## 暗黙的戻り値

ギリシャ文字を含む定義は JavaScript のアロー関数に変換されます。  
関数本体は式だけで構成されるため、`return` を書かなくても式の値がそのまま戻り値になります。

```logos
hypotenuse ≔ √(α² + β²)
```

```js
const hypotenuse = (α, β) => Math.sqrt(((α ** 2) + (β ** 2)));
```

このように、Logos では数式をそのまま定義として書くことで、引数と戻り値を簡潔に表現できます。

***

## 設計思想

Logos は、`function`、引数リスト、`return`、セミコロンのような定型的な記述を減らし、数式をそのまま定義として書けるようにすることを目指しています。

Unicode の論理・数学記号は入力しやすいとは限りませんが、意味を圧縮して読みやすくできる可能性があります。  
また、AI がコードを生成する場面では、記述量の削減にも役立つことを期待しています。  

## 現在使える構文

### 定義

定義には `≔`（または ASCII の `:=`）を使います。  
定義名には英字、数字、アンダースコアを使えます。

```logos
answer ≔ 42
answer_copy := 42
square ≔ α²
cube ≔ α³
```

### 数学定数とリテラル

`π` と `∞` は組み込みの数学定数です。  
また、`⊤` と `⊥` は真偽値リテラル、`∅` は空集合リテラルです。  
JavaScript では以下のように変換されます。

- `π` → `Math.PI`
- `∞` → `Infinity`
- `⊤` → `true`
- `⊥` → `false`
- `∅` → `new Set()`

```logos
circle_ratio ≔ π
unbounded ≔ ∞
flag ≔ ⊤
empty ≔ ∅
```

```js
const circle_ratio = Math.PI;
const unbounded = Infinity;
const flag = true;
const empty = new Set();
```

### 式

現在は次の式を使えます。

| Logos | 用途 | 変換例 |
| --- | --- | --- |
| `+` `-` `*` `/` | 四則演算 | |
| `=` `≠` `<` `>` `≤` `≥` `≡` `≈` | 比較（`=` `≡` は厳密等価、`≈` は `almostEqual`） | `α ≈ β` → `almostEqual(α, β)` |
| `←` | 代入・再代入 | `α ← β` → `(α = β)` |
| `¬` | 否定 | `¬α` → `(!α)` |
| `∧` `∨` `⇒` `⇔` `⊕` | 論理（積・和・含意・同値・排他的論理和） | `α ⇒ β` → `(!α \|\| β)`, `α ⊕ β` → `(α !== β)` |
| `↦` `→` | 明示的アロー関数 (マッピング) | `x ↦ x²` → `x => (x ** 2)` |
| `∘` | 関数合成 | `f ∘ g` → `((...args) => f(g(...args)))` |
| `|>` | パイプライン | `x |> f(a)` → `f(x, a)`, `x |> f |> g` → `g(f(x))` |
| `^` `²` `³` `⁴` `⁻¹` `¹⁰` | べき乗 (任意のUnicode上付き指数) | `α²` → `(α ** 2)`, `α⁻¹` → `(α ** -1)` |
| `x₀` `x₁` `α₁` | 下付き添字 (添字アクセス・暗黙引数) | `x₀ + x₁` → `(x[0] + x[1])`, `α₁ + β₂` → `(α, β) => (α[1] + β[2])` |
| `√` | 平方根 | `√(α)` → `Math.sqrt(α)` |
| `∈` `∉` | 集合の帰属・非帰属 | `α ∈ set` → `set.has(α)`, `α ∉ set` → `(!set.has(α))` |
| `∩` `∪` | 共通部分・和集合 | `A ∩ B` → `new Set([...A].filter(x => B.has(x)))`, `A ∪ B` → `new Set([...A, ...B])` |
| `∖` `×` | 差集合・直積 | `A ∖ B` → `new Set([...A].filter(x => !B.has(x)))`, `A × B` → 直積 `new Set(...)` |
| `⊆` `⊂` | 部分集合・真部分集合 | `A ⊆ B` → `[...A].every(x => B.has(x))`, `A ⊂ B` → 部分集合かつ `A.size < B.size` |
| `‥` | 範囲 | `1‥10` → `range(1, 10)`, `0‥<n` → `range(0, n, true)` |
| `∀` `∃` `∄` | 量化 (全称・存在・非存在) | `∀ α ∈ users : α.age ≥ 18` → `[...users].every(α => α.age >= 18)`, `∃ α ∈ users : ...` → `[...users].some(...)`, `∄ α ∈ users : ...` → `![...users].some(...)` |
| `∑` `∏` | 総和・総積 | `∑ α ∈ numbers : α` → `[...numbers].reduce((acc, α) => acc + α, 0)`, `∏ α ∈ numbers : α` → `[...numbers].reduce((acc, α) => acc * α, 1)` |
| `∫` | 定積分・不定積分 | `∫₀¹ α² dα` → `simpson(0, 1, α => (α ** 2))`, `∫ f(α) dα` → `integrate(α => f(α))` |
| `∂` | 偏微分 | `∂(α² + β²)/∂α` → `partial((α, β) => ((α ** 2) + (β ** 2)), 0)` |
| `∇` | 勾配（ナブラ） | `∇(α² + β²)` → `gradient((α, β) => ((α ** 2) + (β ** 2)))`, `∇f` → `gradient(f)` |
| 比較の連結 | チェーン比較 | `0 ≤ α ≤ 10` → `(0 <= α) && (α <= 10)` |
| `⊤` `⊥` | 真偽値リテラル | `true`, `false` |
| `∅` | 空集合リテラル | `new Set()` |
| `()` | 優先順位の指定 | |
| `α.x` | プロパティ参照 | |
| `α[0]` | 添字アクセス | |
| `⟦ ⟧` | アイバーソンの括弧（条件を値に変換） | `⟦α ≥ 18⟧` → `((α >= 18) ? 1 : 0)` |
| `μ` | 最小化演算子（while） | `μ α (α² ≥ 100)` → `(() => { let α = 0; while (!(((α ** 2) >= 100))) α++; return α; })()`（最小の α を返す）。ブロック形式 `μ α` + `←` の更新文 + 条件式で変数更新ループにもなる（「制御フロー」参照） |
| `⇒` `⊤` | if / else（場合分け） | `α ≥ 0 ⇒ α` と `⊤ ⇒ −α` の並び → `((α >= 0) ? α : (-α))` |
| `−` | 単項マイナス（U+2212 対応） | `−α` → `(-α)` |

### 下付き添字

Unicode の下付き添字は、添字アクセスとして扱われます。  
数学では下付き添字は配列やベクトル、行列などの要素を表すことが多いため、この変換のほうがより自然です。

```logos
x₀ + x₁
```

```js
x[0] + x[1]
```

ギリシャ文字の暗黙引数に対しても同様に動作します。

```logos
dist_sub ≔ α₁ + β₂
```

```js
const dist_sub = (α, β) => (α[1] + β[2]);
```

### チェーン比較

比較演算子を連続して書くと、各比較を `&&` で結合したチェーンになります。  
このとき、中間のオペランドは前の比較の右辺と次の比較の左辺を兼ねます。

```logos
in_range ≔ 0 ≤ α ≤ 10
```

```js
const in_range = α => (0 <= α) && (α <= 10);
```

異なる比較演算子を自由に混在させることもできます。

```logos
between ≔ 0 ≤ α < 10
chain3 ≔ a = b ≠ c ≤ d
```

```js
const between = α => (0 <= α) && (α < 10);
const chain3 = (a === b) && (b !== c) && (c <= d);
```

### 集合演算

`∅` で作った空集合や `Set` を対象に、以下の集合演算が使えます。

| Logos | 用途 | 変換例 |
| --- | --- | --- |
| `A ∩ B` | 共通部分 | `new Set([...A].filter(x => B.has(x)))` |
| `A ∪ B` | 和集合 | `new Set([...A, ...B])` |
| `A ∖ B` | 差集合 | `new Set([...A].filter(x => !B.has(x)))` |
| `A × B` | 直積 | `new Set([...A].flatMap(a => [...B].map(b => [a, b])))` |
| `A ⊆ B` | 部分集合 | `([...A].every(x => B.has(x)))` |
| `A ⊂ B` | 真部分集合 | `([...A].every(x => B.has(x)) && A.size < B.size)` |

```logos
in_both ≔ α ∈ A ∩ B
is_sub  ≔ A ⊆ B
```

```js
const in_both = α => (new Set([...A].filter(x => B.has(x))).has(α));
const is_sub = ([...A].every(x => B.has(x)));
```

集合演算子の優先順位は算術演算子より低く、比較演算子より高いため、`α ∈ A ∩ B` は `α ∈ (A ∩ B)` として解釈されます。  
また `∩` より `∪` が低い優先順位なので、`A ∪ B ∩ C` は `A ∪ (B ∩ C)` になります。

### 量化

集合（または配列）に対する全称・存在・非存在の量化を `∀`, `∃`, `∄` で書けます。  
構文は `∀/∃/∄ 変数 ∈ 集合 : 本体` です。束縛変数は暗黙引数には含まれません。

| Logos | 用途 | 変換例 |
| --- | --- | --- |
| `∀ α ∈ A : P(α)` | 全称量化 (すべての要素が条件を満たす) | `[...A].every(α => P(α))` |
| `∃ α ∈ A : P(α)` | 存在量化 (条件を満たす要素が存在する) | `[...A].some(α => P(α))` |
| `∄ α ∈ A : P(α)` | 非存在量化 (条件を満たす要素が存在しない) | `![...A].some(α => P(α))` |

```logos
all_adult  ≔ ∀ α ∈ users : α.age ≥ 18
has_adult  ≔ ∃ α ∈ users : α.age ≥ 18
no_minor   ≔ ∄ α ∈ users : α.age < 18
```

```js
const all_adult = [...users].every(α => (α.age >= 18));
const has_adult = [...users].some(α => (α.age >= 18));
const no_minor = ![...users].some(α => (α.age < 18));
```

本体はコロンの後の改行に続けて書くこともでき、その場合も最後の式が本体になります。  
また、集合部分には `A ∩ B` などの集合演算をそのまま書けます（`∀ α ∈ A ∩ B : ...` は `(A ∩ B)` 全体に対して量化します）。  
量化の対象は配列と `Set` のどちらでも使えます（スプレッドしてから `every` などで処理します）。

```logos
all_in_both ≔ ∀ α ∈ A ∩ B : α > 0
```

```js
const all_in_both = [...new Set([...A].filter(x => B.has(x)))].every(α => (α > 0));
```

### 総和・総積

集合（または配列）に対する総和・総積を `∑`, `∏` で書けます。  
構文は `∑/∏ 変数 ∈ 集合 : 本体` です。束縛変数は暗黙引数には含まれません。  
生成コードは `reduce` を用います（総和は初期値 `0`、総積は初期値 `1`）。

| Logos | 用途 | 変換例 |
| --- | --- | --- |
| `∑ α ∈ A : f(α)` | 総和 | `[...A].reduce((acc, α) => acc + f(α), 0)` |
| `∏ α ∈ A : f(α)` | 総積 | `[...A].reduce((acc, α) => acc * f(α), 1)` |

```logos
total    ≔ ∑ α ∈ numbers : α
sum_sq   ≔ ∑ α ∈ numbers : α²
product  ≔ ∏ α ∈ numbers : α
weighted ≔ ∑ α ∈ items : α.price * α.qty
```

```js
const total = [...numbers].reduce((acc, α) => acc + α, 0);
const sum_sq = [...numbers].reduce((acc, α) => acc + (α ** 2), 0);
const product = [...numbers].reduce((acc, α) => acc * α, 1);
const weighted = [...items].reduce((acc, α) => acc + (α.price * α.qty), 0);
```

量化と同様に、本体はコロンの後の改行に続けて書くこともできます。  
また、対象は配列と `Set` のどちらでも使えます（`Set` には `reduce` がないため、スプレッドしてから処理します）。

```logos
sum_plus_one ≔ ∑ α ∈ xs :
    α + 1
```

```js
const sum_plus_one = [...xs].reduce((acc, α) => acc + (α + 1), 0);
```

### パイプライン演算子

左辺の式を、右辺の関数の**第一引数**として渡します。データ変換の連鎖を読みやすくできます。

```logos
result ≔ numbers |> filter(isPrime) |> map(square) |> sum
```

```js
const result = sum(map(filter(numbers, isPrime), square));
```

- 右辺が関数参照 `f` のとき: `x |> f` → `f(x)`
- 右辺が関数呼び出し `f(a, b)` のとき: `x |> f(a, b)` → `f(x, a, b)`
- 右辺がメソッド `obj.f(a)` のとき: `x |> obj.f(a)` → `obj.f(x, a)`
- 右辺がアロー関数 `(y ↦ y * 2)` のとき: `x |> (y ↦ y * 2)` → `((y => (y * 2)))(x)`
- 右辺が合成 `f ∘ g` のとき: `x |> f ∘ g` → `(((...args) => f(g(...args))))(x)`

パイプライン演算子の優先順位は最も低いため、`x + 1 |> f` は `f(x + 1)` と解釈されます。

> **注**: `filter`, `map`, `sum` などの関数は JavaScript 側で定義してください。また、関数呼び出し構文 `f(x)` 自体もサポートされました（`√` は従来どおり `Math.sqrt` に変換されます）。

### インデントブロック

`≔` の後に改行とインデントを続けることで、**複数行ブロック**を定義できます。  
ブロック内でローカル変数を定義し、**最後の式を暗黙的に戻り値**とします。  
生成コードはローカル変数を `const` で宣言した**関数スコープ**になります。

```logos
distance ≔
    γ ≔ α.x - β.x
    δ ≔ α.y - β.y
    √(γ² + δ²)
```

```js
const distance = (α, β) => {
    const γ = (α.x - β.x);
    const δ = (α.y - β.y);
    return Math.sqrt(((γ ** 2) + (δ ** 2)));
};
```

- 暗黙引数はブロック全体の自由変数（ギリシャ文字）から自動収集され、ブロック内の定義名は除外されます。
- ブロック内の定義は依存順に並べ替えられるため、**前方参照**（後で定義した名前を先に使う）も可能です。循環参照はエラーになります。
- ブロック内には定義のほか、**式文**（関数呼び出しや再代入 `←` など）も書けます。最後の式文が戻り値になります。
- 本体が式 1 つだけの場合は従来どおりインラインのアロー関数に短縮されます。
- インデントは一貫している必要があります（タブは 4 スペース換算）。インデントを伴わないブロックはエラーになります。
- 量化（`∑`, `∀` など）の本体もコロンの後の改行とインデントで書けます。

### 制御フロー

条件分岐（if / else）・条件の値化・while ループを、英語キーワードではなく**論理記号**で書けます。

**if / else（`⇒`・`⊤`）**  
ブロックの末尾に `条件 ⇒ 結果` の並びを書くと、ネストした三項演算子に変換されます。最後の `⊤ ⇒ 結果` が else 節です。

```logos
abs ≔
    α ≥ 0 ⇒ α
    ⊤     ⇒ −α
```

```js
const abs = α => {
    return ((α >= 0) ? α : (-α));
};
```

- `⊤` は else を表します。`⊤ ⇒ A` は単に `A` に変換されます。
- 3 つ以上の分岐もネストした三項演算子になります（例: `α < 0 ⇒ 0` / `α > 10 ⇒ 10` / `⊤ ⇒ α`）。
- `⊤` を伴わない単一の `P ⇒ A` は、論理含意 `(!P || A)` としてコンパイルされます。

**アイバーソンの括弧（`⟦ ⟧`）**  
`⟦P⟧` は条件 `P` を値（真なら `1`、偽なら `0`）に変換します。

```logos
adult ≔ ⟦age ≥ 18⟧
```

```js
const adult = ((age >= 18) ? 1 : 0);
```

- `[ ]` は配列リテラルに使うため、アイバーソン括弧は二重ブラケット `⟦ ⟧` としています。

**最小化演算子（`μ`・while）**  
`μ α (P(α))` は、`P(α)` が成り立つ最小の `α ≥ 0` を探索します（while ループ）。

```logos
n ≔ μ α (α² ≥ 100)
```

```js
const n = (() => { let α = 0; while (!(((α ** 2) >= 100))) α++; return α; })();
```

上の例は `n = 10` になります。

**変数の更新を伴うループ（`μ` + `←`）**  
`μ` の後に改行とインデントでブロックを続けると、`←`（再代入）による変数更新を伴う while ループになります。ブロックには `x ← 式` の更新文を並べ、**最後の文はループの条件式**（止まる条件）にします。ループは条件が成り立つまで更新文を実行し、束縛変数 `α` の最終値を返します。

```logos
total ≔ μ s
    s ← s + α
    α ← α + 1
    α > 10
```

```js
const total = (() => { let s = 0; let α = 0; while (!((α > 10))) { (s = (s + α)); (α = (α + 1)); } return s; })();
```

上の例は `1 + 2 + … + 10 = 55` を `total` に返します。

- `μ` の束縛変数（上の例では `s`）と、ブロック内で `←` により更新される変数は、**ループ内のローカル変数**として `0` で初期化されます。
- 束縛変数が `←` で更新されない場合は、自動的に `α++` されます（`μ α (P(α))` と同じ挙動）。
- ループ外のギリシャ文字変数（上の例の `α`）は暗黙の引数として捕捉されます。

**単項マイナス（`−`）**  
`−`（U+2212）と ASCII の `-` はどちらも単項マイナスとして使えます（`−α` → `(-α)`）。二項の減算にも両方使えます。

### 微積分記号（∫・∂・∇・′）

`∫`（積分）、`∂`（偏微分）、`∇`（勾配）、`′`（導関数）を数式のまま書けます。  
`∂`・`∇`・`′` は**記号微分**により厳密な導関数を生成します（多項式・積・商・冪・`√`・初等関数（連鎖律）に対応）。式をそのまま微分できない場合（関数参照や未知の関数呼び出しなど）は**数値計算**（有限差分）にフォールバックし、そのときだけ先頭に数値計算用ランタイムが注入されます。`∫` は常に数値積分（シンプソン則）です。

| 記号 | 名称 | 構文 | 変換例 |
| --- | --- | --- | --- |
| `∫` | 定積分 | `∫₀¹ α² dα` | `simpson(0, 1, α => (α ** 2))` |
| `∫` | 不定積分 | `∫ f(α) dα` | `integrate(α => f(α))` |
| `∂` | 偏微分 | `∂(α² + β²)/∂α` | `(α, β) => (2 * α)` |
| `∇` | 勾配 | `∇(α² + β²)` | `(α, β) => [(2 * α), (2 * β)]` |
| `′` | 導関数 | `(α²)′` / `f′` | `α => (2 * α)` / `partial(f, 0)` |
| `″` | 二階導関数 | `(α²)″` / `f″` | `α => 2` / `partial(partial(f, 0), 0)` |

```logos
area ≔ ∫₀¹ α² dα            # 定積分（面積）
antideriv ≔ ∫ α² dα         # 不定積分（関数を返す）
deriv ≔ ∂(α² + β²)/∂α      # 偏微分（厳密）
grad ≔ ∇(α² + β²)           # 勾配ベクトル（厳密）
prime ≔ (α²)′              # 導関数（プライム）
```

```js
// 生成コードの末尾（const 文）:
const area = simpson(0, 1, α => (α ** 2));
const antideriv = integrate(α => (α ** 2));
const deriv = (α, β) => (2 * α);
const grad = (α, β) => [(2 * α), (2 * β)];
const prime = α => (2 * α);
```

- **定積分**: `∫下付き上付き f d変数`。範囲は Unicode の下付き・上付き文字（`₀`, `¹` など）で書き、**両方必要**です（片方だけはエラー）。`d` と変数は `dα` のように続けて書けます（`d α` と空白を入れても可）。
- **不定積分**: 範囲を省略すると `integrate(f)` になり、`(下限, 上限) => 定積分` の関数を返します（`F(0, 1)` と呼び出すと定積分の値になります）。
- **偏微分**: `∂式/∂変数`。`∂` をまたぐ `/` は除算ではなく偏微分記号とみなされます。`∂(α² + β²)/∂α` は「`α` による偏微分」を表し、返り値は点を渡すと偏微分係数を返す関数です（`deriv(2, 3)` → `4`）。多項式・積・商・冪・`√`・初等関数（連鎖律）は**記号微分**で厳密な式になります。関数参照の場合は `∂f/∂α` → `partial(f, 0)` の数値計算になります。
- **勾配**: `∇式`（または関数参照 `∇f`）は、全変数による偏微分を並べたベクトル場を返します（`grad(2, 3)` → `[4, 6]`）。式が記号微分できる場合は各成分が厳密な式になります。
- **プライム（導関数）**: `f′` は関数参照 `f` の導関数（`partial(f, 0)`）、`f″` は二階導関数です。`(α²)′` のように式に付けても書けます。その場合、式の**最初のギリシャ文字**（α, β, … のアルファベット順）で微分します。`(α ↦ α²)′` のようにインラインのアロー関数に付けると、本体を記号微分します。
- **初等関数の微分（連鎖律）**: `∂sin(u)/∂α` → `cos(u)·u′`、`∂cos(u)/∂α` → `−(sin(u))·u′`、`∂exp(u)/∂α` → `exp(u)·u′`、`∂ln(u)/∂α` → `u′/u`。関数呼び出しの `sin`/`cos`/`exp`/`ln`/`sqrt` は `Math.sin` などに変換されます。
- **一般の冪**: 指数が変数に依存する場合、一般の冪則 `d(u^v)/dα = u^v·(v′·ln(u) + v·u′/u)` を使います（例: `∂(α^α)/∂α` → `α^α·(ln α + 1)`、`∂(2^α)/∂α` → `2^α·ln 2`）。指数が変数に依存しない（定数）場合は従来どおり `v·u^(v−1)·u′` です（例: `∂(α^β)/∂α` → `β·α^(β−1)`）。
- **負の単項演算子 `-`**: 数値の負号は `(-...)` の形で出力され、`-(-x)` → `x`、`-(数値)` → 畳み込み後の数値リテラルに簡約されます。

```logos
r ≔ ∂sin(α)/∂α        # → Math.cos(α)
s ≔ ∂cos(α)/∂α        # → −Math.sin(α)
t ≔ ∂exp(α)/∂α        # → Math.exp(α)
u ≔ ∂ln(α)/∂α         # → 1/α
v ≔ ∂(sin(α)²)/∂α     # → 2·sin(α)·cos(α)（連鎖律）
w ≔ ∂(α^α)/∂α         # → α^α·(ln α + 1)（一般の冪則）
x ≔ ∂(2^α)/∂α         # → 2^α·ln 2
y ≔ ∂(α^β)/∂α         # → β·α^(β−1)（β は α に依存しないので定数指数の規則）
```

```js
const r = α => Math.cos(α);
const s = α => (-Math.sin(α));
const t = α => Math.exp(α);
const u = α => (1 / α);
const v = α => ((2 * Math.sin(α)) * Math.cos(α));
const w = α => ((α ** α) * (Math.log(α) + 1));
const x = α => ((2 ** α) * Math.log(2));
const y = (α, β) => (β * (α ** (β - 1)));
```
- `∫` は常に数値積分（シンプソン則）です。`∂`・`∇`・`′` は記号微分できない式に限り数値計算（有限差分）にフォールバックします。
- `∮`（周回積分）は複素数ランタイムが必要なため、**未実装**です（今後の構想を参照）。

zx src/cli.js example/index.logos

| --- | --- |

## 今後の構想

以下はメモに記載されている機能拡張・仕様案です（制御フローはすべて実装済みのため、ここには残りの構想のみを記載します）。

### 1. 表記法・Unicode識別子・型システム構想

- **Unicode数学スタイルの識別子**: 太字 (`𝐀`, `𝐱`)、イタリック (`𝑓`, `𝑥`)、筆記体 (`𝒜`, `𝒳`)、フラクトゥール (`𝔄`, `𝔅`) 等をそのまま識別子としてサポート
- **型注釈構想 (TypeScript等へのコンパイル)**: 黒板太字 (`ℕ`, `ℤ`, `ℝ`, `ℂ`) を型注釈として利用 (例: `age : ℕ`)

### 2. 微積分記号の活用（一部実装済み）

`∫`（積分）・`∂`（偏微分）・`∇`（勾配）・`′`（導関数）は**実装済み**です（「微積分記号（∫・∂・∇・′）」の節を参照）。  
`∂`・`∇`・`′` は多項式・積・商・冪・`√`・初等関数（連鎖律）に対して**記号微分**（厳密な式の出力）に対応しています。以下は未実装の構想です。

- **`∮`（周回積分）**: 閉曲線に沿った複素積分。複素数ランタイムが必要なため、実装コストが高い（難易度: **Hard**）。
